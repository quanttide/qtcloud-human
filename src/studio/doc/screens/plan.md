# 计划页面规划

这个页面的主体是**计划管理**：招聘计划、培训计划、绩效计划、薪酬结算计划等方方面面计划的列表与进度。计划先行，执行与记录落在各模块。

## 内容原则

- **计划涵盖各模块**：招聘计划、培训计划、绩效计划、薪酬计划……一类计划一条线
- **计划驱动执行**：计划定义周期与目标，模块页面承载执行记录，进度回填到计划
- 状态清晰：草稿 / 进行中 / 已完成，进度可追踪

## 入口与鉴权

- 入口：工作台计划入口，面向 HR 与带教人
- 鉴权：HR 创建与调整计划；相关人员查看进度
- 计划完成后归档，关联记录可回溯

## 页面结构

### 计划头部区

- 计划总览：进行中 X 项、本季度完成 X 项
- 按类型筛选（招聘/培训/绩效/薪酬）

### 计划列表区（主体）

- 计划条目：类型徽标、标题、周期、状态徽标、进度说明
- 状态：草稿 / 进行中 / 已完成

## 组件明细

| 组件 | 使用位置 |
|------|---------|
| 计划头部卡 | 页面顶部（进行中/完成统计） |
| 计划条目 | 列表区（类型徽标、标题、周期、状态、进度） |

## 数据与契约

- `plan`：计划（类型、标题、周期、状态、进度）
- 状态枚举：`draft` / `doing` / `done`

## 边界条款

- 计划定义周期与目标，执行记录在各模块，进度由模块记录回填
- 已完成计划归档，不做追溯修改
