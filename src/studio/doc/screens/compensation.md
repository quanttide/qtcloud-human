# 薪酬页面规划

这个页面的主体是**有效工时结算**：展示一个人在一段薪酬周期内的有效工时记录，按职级决定的时薪水平结算弹性薪资。实习生计薪不按固定月薪，而是按实际有效工时计薪——工时记录可回溯，结算结果可验证。

## 内容原则

- **弹性薪资**：按有效工时结算，不做固定月薪；工时多劳多得、少劳少得
- **时薪由职级决定**：职级等级映射时薪水平，职级越高时薪越高（见职级等级规范）
- **有效工时**：实际投入工作的时间，排除无效等待与无关事项——记录即结算依据
- 结算结果由工时与时薪推导，可回溯

## 入口与鉴权

- 入口：工作台薪酬入口，面向员工本人、直属上级、HR
- 鉴权：员工可查看自己的工时与结算；上级可确认下属工时；HR 维护时薪水平与结算
- 工时记录确认后冻结，结算完成后归档

## 页面结构

### 薪酬头部区

- 员工：姓名、身份（岗位/职级）
- 薪酬周期：结算周期（月度）、周期状态

### 有效工时记录区（主体）

- 工时条目：日期、任务、有效工时（小时）——结算依据，事实可回溯
- 与绩效记录同构：工时即行为成果的时间维度，同一份记录风格

### 时薪对照区

- 职级-时薪表：职级等级 → 时薪水平（如 专员 ¥20/h、高级 ¥30/h、资深 ¥40/h）
- 当前员工职级与时薪高亮

### 结算结果区

- 结算明细：总有效工时 × 时薪 = 应发金额
- 调整项：补发/扣除（如有）→ 实发金额

## 组件明细

| 组件 | 使用位置 |
|------|---------|
| 薪酬头部卡 | 页面顶部（员工、职级、薪酬周期） |
| 工时记录条目 | 记录区（日期、任务、有效工时） |
| 时薪对照卡 | 时薪区（职级-时薪表，当前职级高亮） |
| 结算结果卡 | 结算区（总工时、应发、调整、实发） |

## 数据与契约

- `compensation`：薪酬结算聚合（员工、职级、周期、时薪、工时明细、结算结果）
- `work_record`：有效工时记录（日期、任务、小时数）——页面主体
- `rate`：职级-时薪对照（职级等级 → 时薪水平）
- `settlement`：结算结果（总有效工时、应发、调整、实发）

## 边界条款

- 时薪水平由职级决定，职级调整后按新职级计薪
- 有效工时记录确认后冻结，结算依据记录而非口头
- 弹性薪资反映实际投入，不为不满周期补足
