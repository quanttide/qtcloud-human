# qtcloud_hr_studio 页面与组件规划

qtcloud_hr_studio 是量潮人事云工作台——招聘筛选的网关，也是企业绩效管理的工作台。绩效围绕职级制度运行：目标设定、过程记录、周期评估、结果确认。

## 页面规划

| 页面 | 路由 | 内容 |
|------|------|------|
| 招聘筛选网关 | `/` | 投递邮件初筛：正文/自荐检测，自动通过或拒绝，人工复核。已实现于 `lib/main.dart` |
| 绩效页面 | `/performance` | 绩效记录展示：一个人在一段绩效周期里做了什么——行为成果记录（时间、事项、结果），与前台结果对齐。详细规划见 [screens/performance.md](./screens/performance.md) |

## 组件规划

- 绩效头部卡：员工、身份、绩效周期
- 行为成果记录条目：时间、事项、结果
- 任务记录条目：任务、过程、结果
- 指标看板卡：数字资产贡献统计（参考指标）
- 评估结果卡：等级、署名评语、面谈

## 数据模型

与前台结果对齐，同一份契约、同一种展示：

- `record`：行为成果记录（时间、事项、结果）——页面主体
- `cycle`：绩效周期（周期、阶段状态）
- `metric`：参考指标（数字资产贡献统计，仅参考）
- `assessment`：评估（评估者、等级、评语）
